# Maths Adventure – The Lost Kingdom

Offline maths game for Class 6 students (8 regions plus a Boss Battle).

- **Play online / install on Android:** open the GitHub Pages link, then Chrome menu > Install app (works offline afterwards).
- **Android APK:** go to the Releases page and download `MathsAdventure.apk`. It is built automatically by GitHub Actions on every push.
- **Files:** `index.html` is the whole game. `sw.js` and `manifest.webmanifest` make it work offline.
